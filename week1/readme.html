"Creative Coding Is..."

an extremely intriguing art form. It's a way for creatives to express themselves through artistic programming. Utilizing code to express themselves, investigate a topic artistically, or simply to design. It answers a very large question I had when I first learned about IDM. I saw all of this impressive work being done with complex code and wondered often about how fascinating that the code was not only used for function but for seemingly intimate or experimental work. I understand fully now, after my first Creative Coding lesson and most certainly after my first assignment which was research-based: creative coding is just that. Coding creatively. It's in the name!
