Christmas Cheer

I was trying to create a Christmas tree utilzing green triangles and a brown rectangle. The goal was that each time the user clicked, the bulbs would move around on the tree and change colors. But after accidentlly erasing my work the first time, I opted for something simpler. It was orginally a tree against a red background; but I changed the background to green now to imply the circles are bulbs within the tree.
